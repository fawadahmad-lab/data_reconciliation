Download every row (CSV) · Assumptions and known failures

  • Rows are matched by delivery (GRN) number. Compared: date, supplier, item, lot, quantity with unit.
  • Lengths are compared as real length (1 yd = 0.9144 m). H202 is read as H2O2.
  • An unclear value is never guessed or filled from another source. It is blank and amber, and counts as Mismatched ("could not confirm").
  • OCR can read a wrong digit confidently (for example 4 as 9). Format rules, confidence and the number-sequence check catch many, not all. A person confirms the page before comparing.
  • A row the OCR never found cannot be caught by the comparison. The sequence gap and the row counts are the guard.
  • If OCR fails, the page opens as an empty table to type in. Reference correction only applies to pages that match the reference register; other pages stay as OCR read them.
